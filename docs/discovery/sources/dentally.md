# Dentally

- **URL**: https://dentally.com/
- **Fecha de investigación**: 2026-11-17

## Problema que resuelve

"The dental software solution for stress-free dentistry": gestión dental en la nube para trabajar desde cualquier lugar.

## Usuarios objetivo

Grupos multi-sede, consultorios de una sede y nuevos, y consultorios del NHS/HSC (Reino Unido), con presencia en Australia, Canadá, Irlanda y Nueva Zelanda.

## Features detectadas

- Reserva online mediante portal del paciente
- Recordatorios y confirmaciones automáticas
- Listas de espera, "smart booking" y relleno de turnos de último momento (short-notice appointment filler)
- Charting eficiente, notas con IA, imágenes con detección por IA (Dentally Vision)
- Marketplace de integraciones y Developer Hub
