# Mockups C-10 · Reserva pública

Este directorio contiene los mockups estáticos de alta fidelidad para la feature de reserva pública.

## Pantallas

1.  **Selección** (`reserva-seleccion.html`): Paso 1 (Prestación), Paso 2 (Día) y Paso 3 (Horario). Incluye navegación semanal y salto por fecha.
2.  **Formulario** (`reserva-formulario.html`): Paso 4 (Tus datos). Formulario de contacto con validación y resumen.
3.  **Éxito** (`reserva-exito.html`): Confirmación del turno reservado y aviso de email enviado.
4.  **Conflicto** (`reserva-conflicto.html`): Estado de error cuando el horario fue tomado mientras se completaba el formulario.
